# Mitmachen

Danke, dass du helfen willst. Am meisten hilft ein Hinweis auf einen Fehler.

## Fehler melden

Öffne ein [Issue](https://github.com/ITDavid04/Lern-Wiki/issues/new/choose)
mit der Vorlage „Fehler im Inhalt melden". Wichtig sind:

* welcher Artikel und welcher Abschnitt,
* was falsch ist und was richtig wäre,
* wenn möglich eine Quelle (Gesetz, Norm, Herstellerdoku, Prüfungskatalog).

Kein GitHub-Konto? Dann per E-Mail, siehe [Impressum](IMPRESSUM.md).

## Änderungen vorschlagen (Pull Request)

1. Forke das Repository und lege einen Branch an.
2. Ändere die Markdown-Datei. Halte dich an den Aufbau der übrigen Artikel.
3. Beschreibe im Pull Request kurz, was du geändert hast und warum.
4. Ein automatischer Check prüft jeden Pull Request (Pflichtangaben, gesperrte Begriffe). Erst wenn er grün ist, kann die Änderung in die Wiki-APP.

Bitte nur Inhalte einreichen, die du selbst geschrieben hast oder die unter
einer passenden freien Lizenz stehen. Keine Texte, Aufgaben oder Grafiken aus
Kursunterlagen, Büchern, Prüfungen oder Webseiten kopieren.

## Lizenz deiner Beiträge

Mit einem Pull Request erklärst du dich einverstanden, dass dein Beitrag unter
denselben Lizenzen veröffentlicht wird wie das Wiki: Texte unter
[CC BY-SA 4.0](LICENSE), Code unter [MIT](LICENSE-CODE). Du wirst in der
Versionsgeschichte als Autor oder Autorin genannt.

## Umgangston

Sachlich, freundlich und geduldig, so wie man es sich selbst in der ersten
Woche einer Umschulung wünscht.
